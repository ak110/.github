# アクセシビリティの共通方針

Web画面は WCAG 2.2 AA を目標とします。Windowsネイティブ画面は [WCAG2ICT](https://www.w3.org/TR/wcag2ict/) を参考に、キーボード、表示設定、UI Automation と実際の支援技術で利用できる状態を目指します。CLIは色や画面の動きだけに頼らず、端末でもパイプやリダイレクトでも意味が伝わる出力を目指します。

障壁の報告に、障害の開示、スクリーンショット、録画は求めません。報告には各製品の `ACCESSIBILITY.md` が示す報告先を使ってください。

UIを変更する際に宣言を見直します。各製品の宣言には、対象面、確認した環境・版・日付・結果、未検証の範囲、既知の障壁と回避策、報告先を記載します。
